# Security & Privacy Policy

## No-Logs Commitment
Protocol Z adheres to a strict zero-knowledge, zero-logs policy:
- Servers run entirely in RAM (RAM-only file system).
- No browsing history, DNS queries, connection timestamps, or originating IP addresses are ever stored on disk or transmitted to third parties.

## Reporting Vulnerabilities
If you discover a security issue or vulnerability, please contact us directly via Telegram: [@ProtocolZ_Support](https://t.me/ProtocolZ_Support).
